# Scripts

This directory contains command-line helpers for validation, content generation,
and template maintenance tasks.

Ownership: template-owned. Downstream edits are allowed, but they are local
divergence unless the script change is contributed upstream.

See [Repo Ownership](../docs/repo-ownership.md) for the full policy.

`figures/` holds optional Python tools for recovering chart data from PDFs;
see [Figures](../docs/figures.md).

`gallery.ts` (`npm run gallery`) regenerates the device-framed screenshots in
[docs/gallery](../docs/gallery/README.md) from a running site.
