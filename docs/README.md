# Documentation

This directory explains how to adopt, configure, sync, and maintain sites built
from the template.

Ownership: template-owned. Downstream sites may add local notes, but shared
workflow documentation should usually be maintained upstream.

See [Repo Ownership](repo-ownership.md) for the full policy,
[Theming](theming.md) for colours, custom themes, and contrast rules, and
[Figures](figures.md) for charts and diagrams drawn at build time.
