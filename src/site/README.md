# Site Overrides

This directory contains the main downstream customization files.

Ownership: site-owned. Use `config.ts` for identity, navigation, homepage
settings, theme choices, publication options, graph behavior, and entry-type
overrides. Use `themes.ts` to define your own colour themes, `fonts.ts` for
typefaces, and `math.ts` for site-specific math macros.

Files here are expected to differ between websites and should usually be kept
when syncing template updates.

See [Repo Ownership](../../docs/repo-ownership.md) for the full policy, and
[Theming](../../docs/theming.md) for colours.
