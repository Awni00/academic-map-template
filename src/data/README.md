# Data

This directory contains structured site data such as publications and news.

Ownership: site-owned. Edit `publications.bib` for publication metadata and
`news.yaml` for updates. `figures/<post>/` holds chart data and its
`provenance.yaml` (see [Figures](../../docs/figures.md)). These files are expected to differ between websites and
should usually be kept when syncing template updates.

See [Repo Ownership](../../docs/repo-ownership.md) for the full policy.
